# Pochta Modules Bot

Телеграм-бот с модульной архитектурой. Модули работают через сессию
Pyrogram, подключаемую самим пользователем. Доступны только владельцам
**Telegram Premium** (либо тем, кому админ выдал ручной Premium).

Первый модуль — **Таймер**: записывает текущее время в `first_name`
пользователя в выбранном формате (`%H:%M`, `%H:%M:%S`, и т.д.) и
периодически обновляет его.

## Что внутри

```
timerbot/
├── bot.py              ← точка входа
├── config.py           ← токен бота, ADMIN_IDS, API_ID/API_HASH
├── database.py         ← SQLite: пользователи, сессии, состояния модулей
├── userbot.py          ← Pyrogram-логин и фоновые задачи модулей
├── keyboards.py        ← клавиатуры с премиум-эмодзи
├── emojis.py           ← все премиум-эмодзи (HTML <tg-emoji>)
├── states.py           ← FSM-состояния
├── modules/
│   ├── base.py         ← интерфейс Module + реестр
│   └── timer.py        ← модуль «Таймер»
├── handlers/
│   ├── start.py        ← /start, главное меню, профиль
│   ├── connect.py      ← подключение Telegram-аккаунта
│   ├── modules_h.py    ← меню модулей и настройка
│   └── admin.py        ← админ-панель
├── requirements.txt
└── README.md
```

## Установка

```bash
cd timerbot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Конфигурация

`config.py` уже содержит:

```
BOT_TOKEN  = 8897460041:AAEAPXrwpXKuhH3MoEoDa2zTbTxhosZUn2Y
ADMIN_IDS  = [7119847306]
```

Чтобы заработал модуль «Таймер», нужны `API_ID` и `API_HASH` —
получите на https://my.telegram.org/apps и подставьте либо в `config.py`,
либо через переменные окружения:

```bash
export API_ID=1234567
export API_HASH=abcdef1234567890abcdef1234567890
```

```bash

```

## Как пользователь подключает модуль

1. `/start` → нажать «Аккаунт» → «Подключить аккаунт»
2. Отправить номер телефона в формате `+71234567890`
3. Telegram пришлёт код в официальный чат **Telegram** — отправить его
   боту с разделителями (например, `1 2 3 4 5`)
4. При включённой 2FA — отправить облачный пароль
5. В разделе «Модули» открыть «Таймер»
6. Выбрать пресет формата (или прислать свой `strftime`) и базовый ник
7. Готово — бот обновляет ник примерно раз в минуту

## Безопасность сессий

`session_string` хранится в локальной SQLite-базе. Доступ к серверу,
на котором крутится бот, эквивалентен доступу к аккаунтам пользователей —
держите его на доверенной машине и не публикуйте дамп `bot.db`.

## Как добавить новый модуль

1. Создайте файл `modules/your_module.py`
2. Наследуйтесь от `Module`, реализуйте `start` и `stop`
3. Вызовите `register(YourModule())`
4. Импортируйте файл в `modules/__init__.py`

Модуль появится в меню «Модули» автоматически.

## Что бот НЕ делает

* Не меняет ник без Pyrogram-сессии — это невозможно через Bot API.
  Поэтому подключение аккаунта обязательно.
* Не оплачивает за вас Telegram Premium. Проверка идёт через
  `User.is_premium` (либо ручной список `MANUAL_PREMIUM_IDS`).
